# Music Recommendation Analysis

## Цель проекта
Исследовать семантические признаки музыкальных треков для задач рекомендаций и реализовать пайплайн по извлечению характеристик.

## Отчет по заданию

### 1. Источники данных
* **Google MusicCaps Dataset** (с платформы Hugging Face).

### 2. Отбор треков
* Произведена выборка треков, обладающих полными текстовыми описаниями.

### 3. Жанры и категории
* Датасет включает разножанровую музыку (электроника, хип-хоп, классика, рок и др.).
* Казначейские признаки закодированы через текстовые аннотации, настроение (меланхоличный, энергичный) и контекст использования.

### 4. Ограничения выборки
* Ограничение выборки до 50 треков для оптимизации локальных экспериментов с эмбеддингами и моделями ранжирования при сохранении жанрового баланса.
